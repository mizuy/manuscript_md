# Prose and figure conventions

House style for manuscripts built with **manuscript_md**. Project-specific claim
boundaries and cohort vocabulary stay in each paper’s
`manuscript_instruction.md` / `comment.md`.

Source of the shared rules: accumulated practice from `pccrc/docs/paper_lag0`
(also mirrored in `profile/rethed/stomach/paper`).

## Scope

Applies to `manuscript.md` and `supplementary.md` from Introduction onward.
Abstract has the exceptions below.

## Prose

1. **No emphasis (`**…**`) in body text**  
   Define terms in plain English (e.g. “index colonoscopy denotes …”).  
   **Exceptions:**
   - Structured Abstract labels only: `**Background and Aims:**` `**Methods:**`
     `**Results:**` `**Conclusions:**` `**Key words:**`
   - Figure / Table legend lead-ins only: `**Figure 1.**` / `**Table 1.**` /
     `**Supplementary Figure 1.**` (text after the label is plain)

2. **No inline code (`` `…` ``)**  
   Do not paste analysis identifiers into the narrative.  
   - Bad: `` `time > 0` ``, `` `id_patient` ``, `` `n_lag0_c >= 25` ``,
     `` `sandwich::vcovCL(...)` ``  
   - Good: “institution-recorded follow-up”, “two-way clustered robust standard
     errors”, “primary WEO outcome definition”

3. **No pipeline identifiers in Methods/Results**  
   Column names, R/Python expressions, task names, and output filenames
   (`table_*.csv`, `fig_*.png`) do not belong in the narrative. Caption-end
   reproducibility notes in Supplement are allowed when needed.

4. **R package names only in Software**  
   - Bad in Methods: “R `survival` package”, `` `lme4` ``  
   - Good in Software: list packages  
   - Good in Methods: “Cox proportional hazards models”, “mixed-effects logistic
     regression”

5. **Association language for observational designs**  
   Prefer association / estimation wording. Causal claims and guideline-rewrite
   language belong only where the project’s `comment.md` explicitly allows them.

## Figures (`fig/`)

1. **No title or subtitle inside the image** for manuscript figures.  
   Exploratory plots in analysis `out/` may keep titles; strip them before sync
   into the paper `fig/` directory.

2. **Captions live in Markdown** (Tables and Figures section), form  
   `**Figure N.** Title sentence.` Include interpretation caveats in the legend
   when needed. Same pattern for Supplementary figures/tables.

3. **Reference images as** `![](fig/name.png)` from `manuscript.md` /
   `supplementary.md`.

4. Sync from analysis tasks with project wrappers (`paper:fig` /
   `paper:fig-audit` or equivalent). Audit before `paper:docx`.

## Tables (`table/`)

1. Numeric CSV + mechanical Markdown companion (`*_csv.md`) in `table/`.
2. Titles, abbreviations, and footnotes stay in the manuscript around
   `@import "table/…"`.
3. Nested category rows: two leading spaces in the first column (see
   [`TABLE_WORD.md`](TABLE_WORD.md)).

## Citations

1. Manuscript cites **pandoc-id only**: `[@Corley2014-fx]`.
2. `references.bib` is regenerated by scanning `manuscript.md` /
   `supplementary.md` — see skill **manuscript-reference**.
3. Literature notes (optional): `reference/md/{pandoc-id}.md` +
   `reference/pdf/` — [`REFERENCE_INGEST.md`](REFERENCE_INGEST.md).
4. Keep a paper-local citation checklist (e.g. `checkme_paper.md`) when the
   reference set is large.

## Project files (not shared)

| File | Role |
|------|------|
| `manuscript_instruction.md` | Project prose + claim/cohort rules |
| `comment.md` | Scientific claims / reviewer responses (not submitted) |
| `checkme_paper.md` | Citation ingest dashboard (project) |

## Grep aids (from paper directory)

```bash
rg '\*\*' manuscript.md
rg '`' manuscript.md
rg -i 'additional supplementary|additional\.md|additional online' manuscript.md supplementary.md
rg '\*\*Supplementary (Table|Figure) [0-9]+' supplementary.md
rg 'Supplementary (Table|Figure) [0-9]+' manuscript.md
```
