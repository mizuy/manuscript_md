# Reference Ingest

Canonical deep doc for the **manuscript-reference** skill
(`skills/manuscript-reference/SKILL.md`).

Keeps paper-specific literature notes, PDFs, and bibliography files in sync with
**Paperpile** (`paperpile.bib`).

For the central Markdown vault workflow that stores long-term literature notes
outside a paper directory, see [`CENTRAL_REFERENCE_VAULT.md`](CENTRAL_REFERENCE_VAULT.md).

## Directory Layout

```text
paper/
  manuscript.md
  supplementary.md
  references.bib              # generated from [@key] scan
  manual_entries.bib          # entries missing from Paperpile
  checkme_paper.md            # optional citation dashboard
  reference/
    reference_keys.txt        # note-collection keys only
    reference.bib             # generated for notes
    md/
      Example2024-aa.md
    pdf/
      Example2024-aa.pdf
```

Use the Paperpile **pandoc-id** as the filename stem and citation key.

## Citation Keys

Manuscript citations use pandoc syntax:

```markdown
Prior studies reported similar outcomes [@Example2024-aa].
```

`references.bib` is generated by scanning manuscript Markdown files. Do **not**
maintain a separate citation-key list for the manuscript.

`reference/reference_keys.txt` is only for the reference-note collection.

## Paperpile resolution

`scripts/build_bibliography.py` / `ingest_reference.py` resolve BibTeX in order:

1. `--paperpile-bib` / CLI argument
2. `$PAPERPILE_BIB`
3. `$PAPERPILE_BIB (required)`
4. `~/Google Drive/My Drive/paperpile.bib` (and related Drive paths)

Set `PAPERPILE_BIB` in Taskfile / shell when the default symlink is missing.

## Building the manuscript bibliography

```bash
cd /Users/mizuy/lab/manuscript_md
export PAPERPILE_BIB=$PAPERPILE_BIB (required)
task paper:build-bib PAPER_DIR=/path/to/paper
```

`task paper:docx` also rebuilds `references.bib` before pandoc.

Keys not found in Paperpile or `manual_entries.bib` fail the build — fix the
key or add a manual entry.

## Literature-note ingest

### Generic (manuscript_md)

```bash
cd /Users/mizuy/lab/manuscript_md
uv run lab-paper ingest-reference --ref-dir /path/to/paper/reference
# or
task paper:ingest-reference PAPER_DIR=/path/to/paper
```

Skill ingest (`skills/manuscript-reference/scripts/`):

- discover keys from `reference/md/*.md` and `reference/reference_keys.txt`
- generate `reference/reference.bib` (via `build_bibliography.py`)
- sync each `md/*.md` **## メタデータ** block (`bib_parse.py`)
- refresh `README.md` **## 一覧** only (preamble above it stays hand-edited)

Do not vendor these scripts into the paper directory.

## Manual Entries

If Paperpile does not contain a needed entry, add it to `manual_entries.bib` in
the paper directory. The bibliography builder reads manual entries alongside the
Paperpile export. Do not hand-edit generated `references.bib`.

## Citation dashboard (`checkme_paper.md`)

```bash
task paper:checkme PAPER_DIR=/path/to/paper
# or
uv run lab-paper checkme --paper-dir /path/to/paper
```

Writes/updates `checkme_paper.md` between markers:

```html
<!-- auto:checkme-dashboard -->
…
<!-- /auto:checkme-dashboard -->
```

Hand-written sections **below** the markers (priority lists, notes) are kept.
Script: `skills/manuscript-reference/scripts/checkme_dashboard.py`.

Columns: paperpile / ingest (`reference/md`) / cited in manuscript|supplementary.

## Note content (recommended)

For drafting-oriented notes under `reference/md/{pandoc-id}.md`:

- **Abstract (English):** full BibTeX/abstract text (copy, do not paraphrase)
- **Abstract (Japanese):** full translation of that English abstract
- PICO/PECO, affiliations, and numeric results when useful for writing

Vault wiki summaries use a different template — see
`paperpile-literature-ingest`. Keep the same pandoc-id / bibtex_key when both
exist.
