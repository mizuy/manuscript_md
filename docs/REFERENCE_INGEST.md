# Reference Ingest

Reference ingest keeps paper-specific literature notes, PDFs, and bibliography files in sync.

## Directory Layout

```text
paper/
  reference/
    reference_keys.txt
    reference.bib
    md/
      Example2024-aa.md
    pdf/
      Example2024-aa.pdf
```

Use the Paperpile pandoc-id as the filename stem and citation key.

## Citation Keys

Manuscript citations use pandoc syntax:

```markdown
Prior studies reported similar outcomes [@Example2024-aa].
```

`references.bib` is generated by scanning manuscript Markdown files. Do not maintain a separate citation-key list for the manuscript.

`reference/reference_keys.txt` is only for the reference-note collection.

## Generic Ingest

```bash
cd /Users/mizuy/lab/paper
uv run lab-paper ingest-reference --ref-dir /path/to/paper/reference
```

The generic ingest can:

- discover keys from `reference/md/*.md` and `reference/reference_keys.txt`
- generate `reference/reference.bib`
- keep `reference_keys.txt` ordered

Project-specific ingest scripts may add richer metadata synchronization, abstract translation, PDF copying, or custom README generation.

## Building Bibliographies

For the manuscript bibliography:

```bash
cd /Users/mizuy/lab/paper
task paper:build-bib PAPER_DIR=/path/to/paper
```

For a reference-note bibliography:

```bash
uv run lab-paper build-bib \
  --paper-dir /path/to/paper/reference \
  --keys-file /path/to/paper/reference/reference_keys.txt \
  -o /path/to/paper/reference/reference.bib
```

## Manual Entries

If Paperpile does not contain a needed entry, add it to `manual_entries.bib` in the paper directory. The bibliography builder reads manual entries alongside the Paperpile export.
